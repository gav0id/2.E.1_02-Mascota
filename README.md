Ejercicio 2.E.1 02 - Mascota

Lógica del programa
A diferencia del ejercicio anterior, en este caso implementé un método constructor parametrizado. Utilicé la palabra reservada `this` para diferenciar los atributos de la clase de los parámetros recibidos, permitiéndome inicializar los datos de cada mascota en el mismo momento exacto de su creación.

Dentro del método `main`, desarrollé la siguiente lógica:
1. Instancié tres objetos `Mascota` (`m1`, `m2` y `m3`), pasándole directamente al constructor los valores correspondientes a un perro y dos gatos.
2. Utilicé el método estático `String.format()` para construir de manera limpia y estructurada una cadena de texto con los datos de cada mascota, guardándolas en las variables temporales `d1`, `d2` y `d3`.
3. Imprimí estas cadenas formateadas por consola para verificar que la información se guardó de forma independiente en cada objeto.
